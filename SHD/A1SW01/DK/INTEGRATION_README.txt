DeutschKompass A1+ v10 – Hören Integration

Based on the prior DeutschKompass_Hoeren_Integrated package (which retained v10 modules).
- 31 imported Hören exercises from Hoeren_A1_App/data.js, with original audio.
- 6 additional training modules extracted from training.html: 47 listening prompts, 80 answer fields, 31 extracted MP3 recordings.
- Original DeutschKompass Hören, Lesen and Diktat modules remain in place.
- All new exercises appear in Hören > Üben, with Zurück zur Übersicht.
- No Tipp spoilers. The additional training modules reveal transcript only after checking answers.
- Where the source has no original recording, the new module uses browser German speech synthesis; available voices vary by device.
- Local progress is stored by the existing DeutschKompass storage API.

Verification: JavaScript syntax and ZIP integrity checked. Full mobile browser interaction and all audio playback were not manually verified.

Open index.html in a browser or deploy the entire folder to a static host. Preserve relative paths.
